How this works

  • Your secret never leaves this server in plain text over the network — it is stored in the database and only used to derive codes.
  • Sign-in still asks for your password first, then the rotating code.
  • A recovery code can substitute for the app exactly once.
  • Disabling 2FA requires your password again, so a hijacked session cannot silently remove it.
