How discounts work

  • Only one coupon applies per order; the best eligible code is always chosen by the customer.
  • Free-shipping coupons zero the shipping fee but never the tax.
  • Discounts apply to the merchandise subtotal, before shipping and tax.
  • Orders can be cancelled while they are still processing — stock returns automatically.
